# TSCQuestões

Banco de questões do ENADE (Tecnologia em Análise e Desenvolvimento de Sistemas), com simulados,
correção automática de objetivas, autoavaliação de discursivas e salas virtuais para professores.

## Rodando localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
